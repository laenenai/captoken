# Public API of github.com/laenenai/captoken, as a golden file.
#
# Regenerate with: go test . -run TestAPIGolden -update-api
#
# "package captoken" is the facade a consumer imports; "package
# captokentest" is the conformance suite it runs against its own wiring.
# The internal packages are listed too, because the facade re-exports their
# types as aliases: a change to one of those signatures changes what a
# consumer sees, even though the import path itself is private. Growing
# this file is a reviewed diff — see CHARTER.md.
